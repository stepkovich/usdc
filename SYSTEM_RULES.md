# Правила системы (зафиксированы 30.09, до событий)

## Переобучение
- СПРИНТЕР: данные с сервера пишутся 24/7 (мейннет). Обучение — автоматом
  каждые 6 часов при наличии свежих данных (лимиты Кегла позволяют несколько
  раз в день). Цель: «учится всегда».
- АНАЛИТИК: планово раз в месяц (1-е число) + ВНЕПЛАНОВО по сигналу:
  средний результат последних 30 живых сделок < 0 → переобучение и экзамен.
  Вспомогательные сигналы: частота сигналов изменилась вдвое; календарный
  минимум раз в месяц.
- КАЖДАЯ установка модели — только через экзамен по предзаписанным
  критериям. Не сдал → старая модель остаётся, в Telegram сообщается.
- Если переобучения подряд не помогают (живая статистика не восстанавливается)
  → снизить ставки/притормозить, не крутить ручку бесконечно.

## Данные и исполнение
- Данные — всегда МЕЙННЕТ (дампы для истории, живой поток/свечи/стакан —
  с боевого рынка).
- Исполнение — сейчас ДЕМО. Переключение на реал: ключи + одна строка
  режима, ~15 минут, по готовому плану (малый профиль первым заходом).

## Роли
- Сервер: торговля 24/7 + сбор данных.
- Кегл: обучение и экзамены (свежие IP — к биржевому API доступа нет,
  к дампам есть).
- Локальная машина: только мониторинг, из цепочки выведена.
