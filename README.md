# USDC Unified — торговая система (Binance фьючерсы)

Два независимых двигателя в одном коде:

## Буря (ml5h) — основной, торгует реальные деньги
- Ест 30-минутные свечи по ~520 USDT-парам.
- LightGBM-модель (24 признака) оценивает каждую монету при закрытии
  свечи: вероятность хода >0.5 ATR за 10 баров (5 часов).
- Кандидаты: p>0.65 (лонг) / p<0.35 (шорт).
- Замки сигналов: «тихая треть» (отсев самых сонных монет по живой
  квантили ATR) и мета-подтверждение (второе дерево, обученное на
  итогах прошлых сигналов, вето при p_win<0.5).
- Вход: post-only лимитка по лучшей цене, TTL 60 сек, невзятый
  сигнал выбрасывается (опция тейкер-фолбэка для демо).
- Выход: будильник ровно через 5 часов (измеренный оптимум), аварийный
  стоп −15%. Биржа — единственный источник правды: реконсиляция каждые
  10 минут, дневная прибыль считается по биржевым потокам
  (сделки+комиссии+фандинг) с полуночи UTC.
- Ограничители: дневной кап убытка, до 24 позиций одновременно.

## Спринтер (lob) — демо-полигон
- Ест поток заявок (depth20+aggTrade) по 36 USDC-парам.
- Своя модель (LightGBM, 13-18 признаков), само-переобучение на Кегле
  с экзаменом: не сдала — остаётся старая.

## Переобучение
Раз в месяц на Кегле (бесплатные GPU): модель Бури + конвейер признаков.
Перед установкой — экзамен на невиданных днях. Не сдала — остаётся старая.

## Судья (ops/daily_judge.py)
Ежедневная тень: прогоняет вчерашние свечи через модель, копит ВСЕ
сигналы (включая отсеянные замками) с флажками — приговор замкам
по накоплении (~1000 сигналов). Сводка в Telegram ежедневно.

## Данные (пишутся сами, вне репозитория)
- Лестница стакана: 36 монет, снимок ~1.3 сек, с 25.09 — на сервере,
  копии на резервной машине и на Kaggle.
- Лента сделок: те же монеты, с 15.10, теми же каналами.

## Запуск
```bash
cp .env.example .env   # ключи биржи (только торговые права, IP-whitelist)
docker compose up -d --build
```
Реал: BOT_MODE=mainnet. Демо: BOT_MODE=demo. Драйверы включаются
флагами ML5H_*, LOB_* в .env (см. .env.example).
