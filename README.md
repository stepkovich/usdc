# USDC Unified — торговая система (Binance фьючерсы)

Архитектура (после упрощения 27.10): **один сервер (DigitalOcean), один бот, один двигатель.**

## Буря (ml5h) — единственный двигатель, торгует реальные деньги
- 30-минутные свечи по ~520 USDT-парам, LightGBM (24 признака).
- Кандидаты: p>0.65 (лонг) / p<0.35 (шорт).
- Замки: «тихая треть» (отсев сонных монет) + мета-подтверждение
  (второе дерево на итогах прошлых сигналов, вето при p_win<0.5).
- Вход: post-only лимитка, TTL 60 сек. Выход: будильник 5 часов,
  аварийный стоп −15%.
- Биржа — источник правды: реконсиляция каждые 10 мин, дневная
  прибыль = биржевые потоки (сделки+комиссии+фандинг) с полуночи UTC.

## Запуск (DigitalOcean)
```
docker compose up -d --build
docker run -d --name unified-real --restart unless-stopped \
  --env-file /root/usdc-real/.env -v /root/usdc-real/data:/app/data \
  usdc-unified python main.py
```

## Месячный цикл переобучения (1-го числа, ops/monthly_retrain.sh)
1. panel_downloader (Кегль) качает свежие свечи с зеркала биржи;
2. ml5h_wide (Кегль GPU): тренировка + экзамен на невиданных кварталах;
   сдала → ml5h.txt автодеплой на сервер, бот перезапускается;
3. storm_meta (Кегль): мета переучивается на исходах сигналов свежей
   Бури → автодеплой.
Не сдала — предыдущая модель остаётся. Всё с уведомлениями в Telegram.

## Судья (ops/daily_judge.py, локально, ежедневно 14:00)
Тень: копит ВСЕ сигналы с флажками замков — вердикты по фильтру/мете
по накоплении. Сводка в Telegram.

## Мониторинг
- watchdog на сервере: контейнер упал → автоподнятие + Telegram;
- ops/system_audit.sh каждые 4ч: сервис, баланс (биржевые потоки),
  позиции, диск → Telegram.
